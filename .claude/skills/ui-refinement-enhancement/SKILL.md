# UI Refinement & Enhancement Skill

## Instructions

1. **UI Analysis**
   - Review existing UI for visual inconsistencies
   - Identify spacing, alignment, and typography issues
   - Check color usage and contrast ratios
   - Evaluate responsiveness on different screen sizes
   - Verify accessibility compliance

2. **Design Consistency**
   - Standardize colors, fonts, and spacing
   - Unify button styles, inputs, and cards
   - Ensure consistent border radius and shadows
   - Apply a shared design system or theme

3. **Layout Improvement**
   - Improve alignment using flex/grid
   - Fix overflow and spacing issues
   - Enhance hierarchy (headings, sections, emphasis)
   - Optimize layout for mobile, tablet, and desktop

4. **Responsiveness**
   - Apply mobile-first principles
   - Use breakpoints for adaptive layouts
   - Ensure images and components scale properly
   - Avoid fixed widths where possible

5. **Accessibility Enhancements**
   - Add semantic HTML elements
   - Improve keyboard navigation
   - Ensure proper ARIA labels
   - Maintain sufficient color contrast
   - Provide focus states for interactive elements

6. **Visual Polish**
   - Improve typography scale
   - Refine padding and margins
   - Add subtle transitions and hover effects
   - Enhance readability and clarity

> ⚠️ Important: Only modify UI/UX, styling, and structure.  
> Do **not** change business logic, API calls, or core functionality.

---

## Best Practices

- Keep changes purely presentational
- Follow WCAG accessibility guidelines
- Maintain design consistency across all pages
- Use reusable utility classes or components
- Test UI on multiple devices and browsers
- Avoid visual clutter
- Keep animations subtle and purposeful
- Preserve existing component behavior
